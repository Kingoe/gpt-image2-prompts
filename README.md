## 如何使用

1. 先从首页精选区快速浏览，找到接近你想要的视觉方向。
2. 进入场景目录或标签页，缩小到更具体的效果范围。
3. 打开单条卡片，直接复制提示词正文，再结合自己的主题词改写。
4. 遇到暂时还没来得及整理的灵感，先放进 [inbox](inbox/README.md)。

## 收录原则

- 中文说明为主，方便整理和检索。
- 提示词正文优先保留英文，必要时混合中文描述。
- 每条内容尽量保留来源链接或明确标记为 `self-curated`。
- 首页只展示精选内容，完整库以分类目录和标签页为准。
