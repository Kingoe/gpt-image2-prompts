# 极简专辑封面

## 适合什么时候用

适合播客封面、音乐封面、图文栏目主视觉、专题入口图。

## 提示词

```text
Create a minimalist album-cover style portrait, large negative space, one striking subject, subtle grain, deep moody palette, elegant framing, premium editorial feeling, understated but memorable, square-friendly composition, room for text placement.
```

## 使用建议

- 对封面类内容很友好，因为天然带留白。
- 如果想更像唱片封面，可以补 `vinyl-era graphic restraint`。
- 如果想更像杂志感封面，可加 `editorial cover aesthetic`。

## 变量说明

- 优先替换提示词里的占位变量，例如 `{主体}`、`{城市名称}`、`{产品名称}`、`{品牌风格}`。
- 如果没有显式占位变量，就替换主体名词、场景名词和发布渠道，保留构图、材质、光线和比例约束。
- 标签和 `scene` 用于检索，不一定需要原样写进生成提示词。

## 生成注意事项

- 生成后优先检查文字、数字、地图、UI 元素和品牌标识是否准确。
- 如果画面包含真实城市、路线、产品结构或界面细节，建议补充更具体的空间关系和视觉约束。
- 如果第一次结果偏乱，先减少信息量，再逐步增加卡片、标签或装饰元素。
