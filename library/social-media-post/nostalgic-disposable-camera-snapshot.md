# 一次性胶片感生活抓拍

## 适合什么时候用

适合生活方式品牌、人物感配图、回忆感主题、Vlog 配图、轻叙事社媒内容。

## 提示词

```text
Create a nostalgic disposable-camera style snapshot of an everyday lifestyle moment, flash-lit subject, imperfect framing, soft grain, slight blur, authentic emotion, casual background details, 2000s memory-photo energy, warm spontaneity, intimate and human.
```

## 使用建议

- 很适合把完美无瑕的 AI 图拉回一点“真实生活”的感觉。
- 可以把 `everyday lifestyle moment` 换成散步、聚餐、通勤、街角店铺等具体场景。
- 想更像老照片，可以加 `overexposed flash, date-stamp feel`。
