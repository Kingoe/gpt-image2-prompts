# 液态玻璃 Bento 社媒图

## 适合什么时候用

适合产品卖点总结、小红书封面图、朋友圈配图、品牌介绍图、应用功能简介图。

## 提示词

```text
Create a premium liquid-glass bento grid social post for [product name], eight clean modules, hero product in the main panel, soft translucent glass cards, derived brand color palette, subtle iconography, minimal labels, elevated product-marketing aesthetic, high readability, elegant layout, modern editorial social media design.
```

## 使用建议

- 把 `[product name]` 换成你的产品名或栏目主题。
- 品牌色很重要，这类图一旦色彩统一就会非常像成熟模板。
- 如果文字太多，可补 `titles only in secondary cards` 控制信息密度。
