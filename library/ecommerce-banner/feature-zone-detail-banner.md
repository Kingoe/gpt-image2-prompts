# 卖点分区详情图

## 适合什么时候用

适合商品详情页、功能亮点图、卖点说明区、产品介绍长页和电商广告图。

## 提示词

```text
Design a clean e-commerce product detail banner with modular feature zones, one hero product, multiple supporting callout panels, subtle icons, modern Chinese retail design language, high readability, premium layout, clear benefit hierarchy, suitable for product detail pages.
```

## 使用建议

- 很适合把商品的 3 到 4 个核心卖点拆开写进去。
- 如果你的产品偏科技感，可以补 `soft futuristic interface accents`。
- 如果偏生活方式品牌，可以补 `lifestyle props and material texture hints`。
