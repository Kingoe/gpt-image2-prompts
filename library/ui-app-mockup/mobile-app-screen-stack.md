## 使用建议

- 最常用的结构就是三张截图，中间主、两边辅。

## 变量说明

- 替换 App 类型、核心页面和视觉主题，例如健身、记账、AI 助手、旅行规划。
- 保留 `mobile app screen stack`、`device mockup`、`clean landing page composition` 来稳定样机展示。
- 页面数量建议 3 到 5 张，分别描述首页、详情页、数据页或操作流。

## 生成注意事项

- 生成的 UI 文案和图标不可直接当真实界面用，适合做概念展示。
- 检查屏幕透视和边框厚度，避免手机像纸片或角度不一致。
- 如果界面信息糊成一团，减少屏幕数量，先生成单屏或三屏版本。
