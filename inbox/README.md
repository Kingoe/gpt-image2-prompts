# Inbox

这里是快速收集区，适合晚上刷到有感觉的内容时先记下来，不要求当场整理完整卡片。

## 使用规则

- 只记录最少必要信息，不要求当场整理成正式卡片
- 可以只记链接，也可以只记提示词正文
- 一条候选尽量保持一小段，避免堆成长文
- 每次整理正式内容时，从这里挑选迁移到 `library/`

## 快速收录格式

### 格式 A：只有链接

```text
链接：`https://example.com`
备注：这一条为什么值得收。
标签：`场景` `效果标签`
```

### 格式 B：只有提示词正文

```text
来源：`user-submitted prompt` / `from screenshot`
拟定标题：`先写一个临时标题`
场景判断：`社媒贴文`
标签：`标签 1` `标签 2`
备注：这一条最值得保留的结构是什么。

提示词：
【直接粘贴原始提示词】
```

### 什么时候可以直接转正式卡片

满足下面 3 条就可以从 inbox 转进 `library`：

- 你已经知道它适合什么场景
- 你愿意下次直接复用它
- 你能说清它来自哪里，或者至少知道它是怎么被你收进来的
